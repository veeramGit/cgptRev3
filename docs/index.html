Multi-Interval Trading Timer

Precision multi-interval candle countdown timers with desktop notifications and embedded audio alerts built for active traders across NSE, global indices, Gold, and crypto markets.

Install from Chrome Web Store

Key Features

  • Multi-Interval Tracking: Run independent 1-minute, 3-minute, 5-minute, 15-minute, and 1-hour candle timers simultaneously.
  • Market Open Synchronization: Pre-configured Market Open times for NSE, global indices, Gold, and cryptocurrency markets.
  • Custom Alert Offsets: Trigger alerts before or after candle close (15, 30, 60, 120, 180 seconds, or custom offsets).
  • Reliable Background Persistence: Timers continue running accurately even when the Chrome extension popup is closed, with state persisted in Chrome storage.
  • Audio & Visual Notifications: Choose between Beep, Double, and Chime alert tones paired with Chrome desktop notifications.
